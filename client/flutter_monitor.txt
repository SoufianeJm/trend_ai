Commands to monitor from another terminal:
==========================================

1. View real-time logs:
   Get-Content flutter_app_phone.log -Wait -Tail 20

2. View current log content:
   Get-Content flutter_app_phone.log

3. Check job status:
   Get-Job -Id 5

4. Get job output:
   Receive-Job -Id 5

5. Stop the Flutter app:
   Stop-Job -Id 5
   Remove-Job -Id 5

6. Restart Flutter app on phone:
   Start-Job -ScriptBlock { Set-Location "C:\Users\TERRA\Desktop\trend_ai\client"; flutter run -d 0H73B17I22104999 --verbose *>&1 | Tee-Object -FilePath "flutter_app_phone.log" }

7. View log file size/info:
   Get-Item flutter_app_phone.log | Select-Object Name, Length, LastWriteTime

8. Monitor in real-time with timestamps:
   while ($true) { Get-Content flutter_app_phone.log -Tail 5; Start-Sleep -Seconds 2; Clear-Host }
